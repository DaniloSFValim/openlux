# Referência visual (não é o site)

`prototipo-openlux.html` é o protótipo aprovado como base visual da reconstrução do front end do OpenLux 2.0
(mapa, lente de comparação, cartão e linha do tempo). Ele **não é publicado** e **não é fonte de dados**:
os números embutidos nele não têm procedência verificada. A reconstrução lê apenas os arquivos publicados em `web/data/`.
